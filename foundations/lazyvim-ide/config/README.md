# Config files

Copies of the Neovim config files that the
[how-to guide](../lazyvim-playground-howto.md) builds, taken from my own
setup so you can compare them with yours.

- `repl.lua`: the one-key runner (F5) and the shell shortcuts (Step 5). Goes
  in `~/.config/nvim/lua/plugins/`.
- `bash.lua`: the Bash language server and tools (Step 5). Goes in
  `~/.config/nvim/lua/plugins/`.
- `formatting.lua`: on-demand formatting (Step 6). Goes in
  `~/.config/nvim/lua/plugins/`.
- `options.lua`: my full `options.lua`. The guide only asks you to add the
  lines at its bottom (Step 6). Goes in `~/.config/nvim/lua/config/`.
- `snacks.lua`: image viewing inside Neovim (Step 8, optional). Goes in
  `~/.config/nvim/lua/plugins/`.

An AI assistant helped draft this setup, as the guide explains.
