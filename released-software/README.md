# Released software

Open-source software I designed, directed and released. Each one is
published in its own public repository. An AI assistant generated the code;
I set the requirements, made the decisions and tested every version.

## What each folder contains

- A write-up of the project: the decisions, the testing and the problems
  found and fixed, opening with a note on how AI was used.
- The screenshots used in the write-up, in `images/`.
- No code. The code, license and release history live in each project's
  own repository, linked below and from the write-up.

Each write-up describes the project as of the release it covers. The
repository and the directory listing always show the latest version.

## The releases

- **Treelights** (Obsidian plugin): highlights code blocks accurately using
  Tree-sitter, and flags security-relevant text in notes: indicators of
  compromise, leaked secrets and hidden characters.
  - [Write-up](treelights-plugin/treelights-plugin-writeup.md)
  - Repository:
    [james-s-pearson/treelights](https://github.com/james-s-pearson/treelights)
  - Directory listing:
    [community.obsidian.md/plugins/treelights](https://community.obsidian.md/plugins/treelights)
- **Neon Alley** (Obsidian theme): one theme with four palettes, in dark and
  light mode, with callouts and tags built for security notes.
  - [Write-up](neon-alley-theme/neon-alley-theme-writeup.md)
  - Repository:
    [james-s-pearson/neon-alley](https://github.com/james-s-pearson/neon-alley)
  - Directory listing:
    [community.obsidian.md/themes/neon-alley](https://community.obsidian.md/themes/neon-alley)
