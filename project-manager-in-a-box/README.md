**Version 0.1 · released October 2026.** This folder is always the latest version. To check you have it, compare the version line on the first page of the playbook with the one here. ## Start here

1. **Read the playbook.** On GitHub, open `01-Playbook/Playbook-Preview.md`, or download `01-Playbook/Project-Manager-in-a-Box.pdf` for clickable links. For the full web book, download **`Project-Manager-in-a-Box.html`** and open it in your browser: a sidebar table of contents, a track switch (Both / Hybrid / Technical) and download buttons for every template.
2. Open **`05-Examples/Project-Workbook-EXAMPLE-Project-Beacon.xlsx`** to see a finished project (the fictional Project Beacon), then use **`03-Project-Workbook/Project-Workbook.xlsx`** for your own. The same folder holds four filled-in Word examples: a charter, a final status report, a closeout report and an acceptance sign-off.
